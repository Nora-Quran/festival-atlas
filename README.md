# Festival Atlas | اطلس جشنواره‌ها

A bilingual (Persian / English) website for the official selections of major film festivals, 2010–2026. It covers 11 festivals (Cannes, Venice and the Berlinale 2010–2026; San Sebastián, Karlovy Vary, Tallinn Black Nights, Annecy, Clermont-Ferrand, IDFA, Tribeca and BFI London 2017–2026), with more listed in the catalogue.

Each film page has:
- the official sources and a verification badge;
- an AI theme analysis grounded only in the official synopsis;
- similar-film recommendations.

**Live site:** https://nora-quran.github.io/festival-atlas/

This repository holds the published copy only. The data is generated by the research toolkit in the (private) PhD_Thesis repository (`festival_research/`), using:

```bash
python -m festival_db site --festivals data/cannes
```

The output folder `site/` is then copied here, and every push to `main` redeploys the site through `.github/workflows/pages.yml`.

The full list of planned improvements is in `ROADMAP.md`.
